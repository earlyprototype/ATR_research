# PR-History Reconstruction — earlyprototype/ATR_research

## SUMMARY

The repo's ~29 PRs (Jul 21–29, 2026) fall into four phases: background docs (#1–#3), the EXP_010c experiment line and its controls (#4, #5, #8/#9/#19, #20, #29, #33, #39, #42, #44, #49), board/coordination infrastructure (#23, #24, #27, #31, #34), and session notes (#47). Every PR is authored, commented on, and merged by the single GitHub identity `earlyprototype`; individual Claude agents are distinguishable only by session-ID trailers. The history shows two systemic coordination failures that the project itself later diagnosed: (a) duplicate work — issue #7 drew three independent permutation-test implementations (#8, #9, #19) and issue #6 drew two (#10, #20), with hypothesis ID H11 claimed three different ways; and (b) branch-topology accidents — PR #20 merged into an already-merged feature branch (12 commits orphaned off `main` for ~3 days until #33 carried them), and PR #5's capstone was stranded on that same dead base until a session-note warning (#47) triggered an explicit rescue (#49). Scientific self-correction is unusually strong for a solo+agents project — review rounds on #33 caught a data-clobbering hazard, a wrong count, a stale map, and two overstated methodological claims — but merge discipline is weak: several experiment PRs merged within 20–120 minutes of opening while the only automated reviewer (CodeRabbit) was rate-limited, i.e. effectively unreviewed. Substantively, the PR record converges on a deflationary arc: the `D` collapse is apparatus-dependent (#39), the "band" is two isolated cells rather than a band (#20/#33), the band window does not recreate Small's geometry (H11 refuted, #5/#49), and the J-lens instrument found "NO COHERENT BAND" and no correlate of the ATR islands (#44) — all stated flatly in the record, to the project's credit.

## RED FLAGS

- **Merge gatekeeping is nominal.** #19 (the canonical permutation implementation) merged 2h02m after opening while CodeRabbit was rate-limited ("Review limit reached" is its only automated comment); #29 merged 20 minutes after opening; #18 merged in 4 minutes. Self-merge by the same identity that authored. The strong review story on #33 is the exception, not the rule.
- **Work-loss near-misses required luck to catch.** #20's 12 commits sat unreachable-from-main for ~3 days; #5's capstone (and the H11 verdict) survived only because one session wrote an explicit rescue warning into a merged note (#47) and TC acted on it (#49). Nothing structural prevents recurrence; no branch protection, no base-branch check, and all 20 remote branches (including long-merged ones) still exist.
- **Record integrity blemishes on main**: the false "#8 merged" statement in #9's thread; two competing pre-registered specs for one control; a redundant spec merged against the merging session's own recommendation.
- **Data-clobbering hazard shipped and its fix shipped broken**: variant runs could silently overwrite registered result artifacts (`results_<tier>.json`); the guard commit `2f488df` then crashed every run (`NameError: name 'suffix' is not defined`) and rejected two experiments' registered commands — caught only because a second agent re-ran things (`e0bf0a7`). The author's own confessed verification method ("grep -E \"Tier=\" piped to head -1... proved the run **started**, not that it **finished**") is a systemic pattern, echoed in #23/#24 and #27.
- **Public repo + shared bot identity**: until #34, any GitHub user could inject content into the board via unauthenticated `BOARD:` comments, and agent markers were forgeable; attribution of scientific work to specific agents rests entirely on honor-system markers and session trailers.
- **Accidental commits of instrument clones/artifacts** (reverted in `60820d7`) and a `.pyc` (#34) show `git add -A` habits operating on a repo that also stores registered scientific artifacts — the same habit class that the overwrite guard exists to contain.
- **Stale open PRs embodying superseded claims**: #10 (open 5+ days, conflicting H11 registrations, duplicates landed work) and #53 (politically-themed experiment, open, unreviewed) are outstanding record liabilities.

## RECOMMENDATIONS

- Adopt a minimal merge gate: no experiment-result PR merges without either a completed CodeRabbit review or a second-session agent review; ban same-session open-and-merge under ~2 hours.
- Require PR base = `main` (or an open PR's branch with an explicit stack note) via a CI check; delete branches on merge; close #10 with a supersession comment mirroring the #8/#5 pattern, and either merge or close #51-style review-only PRs promptly.
- Clean the permutation record: remove or clearly deprecate `PERM_TEST_EXP010c_SPEC.md` (pointer to the canonical `EXP_010c_PERM_SPEC.md`), and append a correction to #9's thread fixing the "#8 merged" misattribution.
- Institutionalize the #33 lesson: verification must check completion (exit codes, artifact digests), not startup; add a CI smoke run of `run_exp010c.py --tier smoke` to completion so a `NameError`-class regression cannot merge.
- The identifier registry (discussion #37) and per-PR board threads directly address the #8/#9/#19 duplication class — make the "check the board before starting" step enforced (the pr-board overlap check already runs; surface it as a required status).
- For leadership readout: the surviving substantive picture is deflationary and internally consistent — `D` collapse is apparatus-conditioned (#39), the "band" is two isolated cells (#33), it does not recreate Small (#49), the J-lens found no coherent band (#44); the one live, fragile positive is the Small-like tensor partition under the `D` mask (ARI 0.200, p=0.0009), which should not be promoted anywhere until its registered arbiters (EXP_013m, natural-energy ARI) run.
